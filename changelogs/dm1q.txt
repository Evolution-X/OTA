This is Android 16 with July 2026 security patches

Notes:
==============================
- LineageOS-based source. Signed build.
- Clean flash mandatory when your build is from Evolution X 8 or lower
- Firmware based on EZA1
- First installation requires OneUI 7 with an unlocked bootloader. Devices with fused 9+ (Global) / 7+ (Chinese) bit are not supported
- If you have issues with VoLTE / VoWiFi, you can disable it via toggle in settings or using adb shell: "adb shell pm disable-user --user 0 me.phh.ims"

Known Bugs:
==============================
- eSIM registration
- HDMI output over USB-C

Device changes:
==============================
- Fixed volume control on calls (thanks to krazey)
- Fixed echo on VoIP calls when using loudspeaker (thanks to krazey)
- Fixed some apps that use audio MMAP being mute
- Updated IMS to version a3fec01ebc4f51c39026565c4a451fef454637fa
