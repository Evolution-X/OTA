This is Android 15 QPR2 with April 2025 security patches

Notes:
==============================
- LineageOS-based source. Signed build.
- Play Integrity passes, RCS works (As of 25/04/2025).
- Includes Dolby Atmos, POCO camera.
- Install this (https://github.com/KernelSU-Next/KernelSU-Next/releases/download/v1.0.6/KernelSU_Next_v1.0.6_12490-release.apk) for root.
- Flash ( https://github.com/Atom-X-Devs/scarlet_xiaomi_sm7325/releases ) NON-ROOT version of kernel to get rid of root.
- If you face any issue ( such as auto reboot ) on scarlet You can flash any alternative kernel from Here ( https://sourceforge.net/projects/poco-x5-pro-roms/files/Kernel )
