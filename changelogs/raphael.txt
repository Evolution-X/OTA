This is Android 15 QPR2 with May 2025 security patches

Notes:
==============================
- LineageOS-based source. Signed build.
- Always dirty flash at your own risk. If your device bootloops, revert to an older build that boots.
- Kernel is already pre-rooted with KSU Next. Just install the KSU Next app.
- Includes Dolby Atmos, Leica camera.

Device changes:
==============================
None

Notable ROM changes:
==============================
Add vendor_overlay support to fsgen
CompositionEngine: Request device composition for the Udfps dim layer
Evolver: Drop ROM-side Play integrity fix
Fix ArrayIndexOfBoundsException in WallpaperManagerService
Fix the system server restart issue caused by the fingerprint framework
