This is Android 16 with August 2026 security patches

Notes:
==============================
- LineageOS-based source. Signed build.
- Clean flash mandatory when your build is from Evolution X 8 or lower
- Firmware based on EZA1
- First installation requires Android 15 version with an unlocked bootloader
- If you have issues with VoLTE / VoWiFi, you can disable it via toggle in settings

Known Bugs:
==============================
- HDMI output over USB-C
- Echo on IMS calls when using loudspeaker
- Recording IMS calls

Device changes:
==============================
- Update to Evolution X 11.10
- New ImsStack (thanks to krazey)
- Switch to displayconfig (thanks to josip-k)
- eSIM support (thanks to josip-k)
- Korean models (SM-S91xN) support
- Update Dolby
